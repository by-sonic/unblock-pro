# UnblockPro 2.0.23 — исправление запуска на Windows

После установки 2.0.22 у части пользователей подключение останавливалось на
«Не удалось подтвердить защиту каталога движка» с окончанием
`Unprivileged write access: C:\`. Переустановка поверх не меняла результат.

Проверка защищённого движка считала некоторые разрешения корня системного диска
опасными для каталога `Program Files`. Правило для **корня тома** уточнено:
разрешение создавать посторонние файлы и каталоги рядом с `Program Files` и
разрешение удалить сам корень больше не блокируют запуск. Возможность удалить
существующий дочерний каталог, менять ACL или владельца по-прежнему блокирует.
Для `Program Files`, каталога установки, EXE, DLL, драйвера и payload-файлов
сохраняется строгая проверка. Права на диске приложение не меняет.

В ошибке теперь указаны SID и числовая маска правила доступа, которое вызвало
отказ. Если после обновления ошибка остаётся, приложите **полный текст ошибки**
к [issue #73](https://github.com/by-sonic/unblock-pro/issues/73). Это позволит
отличить другое нестандартное разрешение диска от исправленного ложного отказа.

Проверены реальные Windows ACL, допустимые и опасные права корня по отдельности,
неизменность строгой проверки под `Program Files`, отказ для portable-каталога,
пользовательской временной папки и junction. Windows CI выполняет эти тесты
перед сборкой. Проверки на компьютере автора скриншота не было: его ACL нам
недоступны.

Windows 10/11 x64: скачайте `UnblockPro-2.0.23-win-setup.exe` и установите
поверх текущей версии или используйте автообновление. Portable-сборка не
выпускается. macOS в этом обновлении не меняется.
