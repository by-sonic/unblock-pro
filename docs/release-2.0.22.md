# UnblockPro 2.0.22 — исправление подключения на macOS

Исправлена регрессия 2.0.21: при подключении появлялась ошибка
`Node.util.isObject is not a function`. Та же ошибка мешала очистке системных
настроек и штатному выходу из приложения. Сообщения: #71 и #46.

Причина — несовместимость старого `sudo-prompt` с Node.js внутри Electron 43.
Библиотека запроса прав заменена на `@vscode/sudo-prompt` 9.3.2; обновлены
импорт и lockfile. Добавлена проверка реального вызова зависимости в Electron
на обеих ОС, отдельно проверяется её наличие и работа внутри собранного приложения.
Проверка останавливается до системного диалога и не меняет сетевые настройки.

Движки и стратегии остались такими же, как в 2.0.21. Этот хотфикс устраняет
ошибку запуска и очистки; доступность сервисов у конкретного провайдера
проверяется отдельно.

## Обновление

- macOS 12+: скачайте `.dmg` или `.zip` для своего процессора и замените приложение
  в «Программах». Если 2.0.21 не даёт выйти из-за этой ошибки, завершите его через
  «Мониторинг системы» и установите 2.0.22. В новой версии воспользуйтесь кнопкой
  «Убрать записи из hosts», затем повторите подключение. Принудительное завершение
  само по себе не выполняет очистку.
- Windows 10/11 x64: установите `UnblockPro-2.0.22-win-setup.exe` или используйте
  автообновление. Portable-сборка не выпускается.

При блокировке первого запуска macOS после перемещения в «Программы»:

```sh
xattr -cr /Applications/UnblockPro.app
```

Если ошибка сохраняется, приложите новый журнал к #71. Проверку настоящего
парольного диалога и состояния сети на macOS 26/27 требуется подтвердить
на машине пользователя; CI не заменяет эту проверку.
