# UnblockPro 2.0.21

## Скачать

- Windows 10/11 x64: `UnblockPro-2.0.21-win-setup.exe`.
- macOS Apple Silicon: `UnblockPro-2.0.21-mac-arm64.dmg` или `.zip`.
- macOS Intel: `UnblockPro-2.0.21-mac-x64.dmg` или `.zip`.

## Стратегии и движок

- Windows: комплект Flowseal обновлён с 1.9.9c до **1.10.2** — 22 профиля,
  включая ALT13 и EXP, актуальные списки доменов и все необходимые payload-файлы.
  ALT13 проверяется первой. Сам winws в этих двух выпусках Flowseal одинаковый;
  обновлены именно профили и данные.
- Исправлен перенос служебного `^!` из BAT: некоторые профили FAKE TLS AUTO
  могли завершаться с ошибкой параметра ещё до проверки подключения.
- macOS: tpws собран из commit `d437963452674faadfd45adcd62466272b5a2fcd` с
  upstream-исправлением стека DNS-потока. Проверка запуска теперь обращается
  к DNS-потоку через SOCKS5. Это исправляет известную причину падения; связь с
  конкретным отчётом #70 ещё требует проверки на машине автора.
- Движок и стратегии обновляются вместе с приложением. Автоматической подмены
  на произвольную новую версию zapret или zapret2 нет.

## Исправления

- Подбор по своему HTTPS-адресу и раздельный результат для YouTube и Discord.
  Если работает только один сервис, интерфейс сообщает об этом.
- Исправлена прокрутка: «Свои домены» и журнал доступны в небольшом окне.
- Журнал сохраняется на диск, его можно скопировать для диагностики.
- macOS сообщает об аварии tpws отдельно от неудачной стратегии; остановка
  дожидается завершения поиска, ошибки восстановления DNS/proxy/pf/hosts видны.
- Удаляются оставшиеся строки hosts, в том числе от старых версий.
- Windows запускает установленный движок только из проверенного защищённого
  каталога Program Files. **Portable-сборка больше не выпускается**: скачайте
  установщик. Для запуска приложению нужны права администратора.
- Убрано применение изменяемого удалённого hosts-файла: данные закреплены в сборке.
- Electron обновлён до 43.7.3, исправлены уязвимости зависимостей.

## Установка и диагностика

Требования: Windows 10/11 x64 или macOS 12 Monterey и новее. Electron 43
не поддерживает macOS 11 Big Sur; минимальная версия указана и в метаданных приложения.

На Windows установите новую версию поверх старой. На macOS обновите приложение
вручную; если система блокирует первый запуск, выполните:

```sh
xattr -cr /Applications/UnblockPro.app
```

После обновления заново запустите автоподбор. Если проблема остаётся, приложите
журнал и укажите ОС, провайдера и неработающий сервис. При падении tpws нужен
`tpws*.ips` из `~/Library/Logs/DiagnosticReports` (удалите личные сведения).
Успешные HTTP/WebSocket-проверки не гарантируют воспроизведение каждого видео
или голосовое соединение Discord. Проверка через VPN не подтверждает обход
блокировок провайдера.
