# UnblockPro 2.0.27 — Firefox на macOS

**В Firefox на macOS при включённом обходе не открывалось большинство сайтов (#81).**
Firefox получает системный прокси macOS как «SOCKS» без номера версии и по
умолчанию понимает его как SOCKS v4. Галочка «Отправлять DNS-запросы через
прокси» (для v5 она включена по умолчанию) у Firefox действует и здесь, поэтому
он отправлял имя сайта по SOCKS4a. tpws из zapret SOCKS4a не поддерживал и
отклонял такой запрос. Chrome и Safari работают с прокси по SOCKS5, поэтому у них
всё было в порядке.

Теперь tpws собирается с небольшим патчем (`src/main/patches/tpws-socks4a.patch`):
имя хоста из запроса SOCKS4a разрешается тем же резолвером, что и для SOCKS5.
Патч применяют и CI, и сборка tpws внутри приложения; если он перестанет
накладываться на новую версию zapret, сборка упадёт, а не выпустит tpws без него.
CI на macOS проверяет SOCKS4a и SOCKS5 настоящими запросами через собранный tpws.

Проверено: исходный и пропатченный tpws собраны из закреплённого коммита zapret
в Linux, `curl --socks4a` к исходному — отказ, к пропатченному — HTTP 200, SOCKS4
по IP и SOCKS5 с именем работают как раньше. Firefox на живом Mac не проверялся.

Настройки Firefox менять больше не нужно.
